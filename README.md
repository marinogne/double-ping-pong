# Double Ping Pong 🏓

## 📌 Sobre o Projeto
Bem-vindo(a) ao clássico jogo de Ping Pong! Prepare-se para uma competição emocionante entre dois jogadores enquanto tentam superar um ao outro em uma partida rápida e dinâmica.

Este projeto tem um valor especial, pois foi desenvolvido durante o Ensino Médio como parte do curso **Alura Start**. Ele marca meus passos no aprendizado de lógica.

## 🚀 Jogue Agora
🔗 **[Clique aqui para jogar o Double Ping Pong](https://marinogne.github.io/double-ping-pong/)**

## 💻 Tecnologias Utilizadas
* **Linguagem:** JavaScript
* **Estrutura e Estilização:** HTML5 e CSS3

## 🕹️ Como Jogar
Chame um amigo para jogar no mesmo teclado! O objetivo é fazer a bolinha passar pela raquete do adversário.

* **Controles do Jogador 1 (Esquerda):**
  * `W` - Move a raquete para cima
  * `S` - Move a raquete para baixo

* **Controles do Jogador 2 (Direita):**
  * `⬆️ Seta para Cima` - Move a raquete para cima
  * `⬇️ Seta para Baixo` - Move a raquete para baixo

## 🧠 Aprendizados
Durante o desenvolvimento deste jogo, pude aplicar na prática conceitos importantes de programação, como:
* Criação e manipulação de variáveis.
* Estruturas condicionais (se a bolinha tocar na borda, faça isso).
* Laços de repetição e funções.
* Detecção de colisão matemática (entre a bolinha e as raquetes).
